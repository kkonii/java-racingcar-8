# java-racingcar-precourse

## 🙋‍♀️사용자 이용 가이드

### 1 단계. 경주 자동차 등록

콘솔에 문구가 뜨면 원하는 이름을 입력해 주세요.

```text
경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
```

<예시 입력>

```text
pobi,woni,jun
```

<br>

<주의 사항>

**지정된 형식**에 따라 입력해 주세요!

- 여러 이름을 입력할 때는 `,`를 구분자로 연결해 주세요
- 비어 있는 이름 값은 입력할 수 없습니다
- 이름의 최대 길이는 `5`자 입니다
- `한글`,`영어`,`숫자` 로 이루어진 이름만 등록할 수 있습니다!

<br>

### 2단계. 진행 횟수 지정

콘솔에 문구가 뜨면 원하는 횟수를 입력해주세요.

```text
시도할 횟수는 몇 회인가요?
```

<예시 입력>

```text
3
```

<br>

<주의 사항>

- 공백으로만 이루어진 값은 입력할 수 없습니다
- 숫자 외의 값은 입력할 수 없습니다
- 최소 `1`회 이상 **실행 가능한 횟수**를 입력해 주세요!

<br>

### 3단계. 경주 게임 진행

한 라운드마다 자동차는 `전진`하거나 `멈춤`으로 경주를 진행합니다. <br>
경주가 진행되면 각 차수별 결과가 출력됩니다

```text
실행 결과
pobi : -
woni :
jun : -

pobi : --
woni : -
jun : --

pobi : ---
woni : --
jun : ---

```

<br>

### 4단계. 게임 종료

가장 먼 거리를 움직인 자동차가 `최종 우승자`로 선별됩니다.<br>
최종 우승자가 출력되면 게임이 종료됩니다

```text
최종 우승자 : pobi, jun
```

## 🖥️ 개발 기능 목록

입력 기능

- [x] 자동차 이름을 입력받는다
- [x] **<예외>** 지정된 구분자가 담긴 형식이 아니면 예외를 발생한다

- [x] 시도 횟수를 입력받는다
- [x] 시도 횟수를 숫자 타입으로 변환한다
- [x] **<예외>** 숫자가 아닌 경우, 예외를 발생한다

- [x] **<공통 예외>** 이름과 시도횟수가 한 개도 입력되지 않으면(공백) 예외를 발생한다

경주 기능

1. 시도 횟수

- [x] **<예외>** 시도 횟수가 0 이하인 경우, 예외를 발생한다

2. 자동차 이름

- [x] 구분자를 제외한 이름들만 모은다
- [x] **<예외>** 중복되는 이름이 존재할 경우 예외를 발생한다
- [x] 각 자동차에 이름을 부여한다
- [x] **<예외>** 이름이 `5`자를 초과하면 예외를 발생한다
- [x] **<예외>** 이름이 `공백`이면 예외를 발생한다
- [x] **<예외>** 이름이 `한글`,`영어`,`숫자` 외의 문자를 포함하면 예외를 발생한다 (띄어쓰기는 허용)

3. 랜덤 숫자 생성

- [x] 0-9 중 랜덤 정수 한 개를 반환한다

4. 전진

- [x] 반환된 숫자가 전진 가능한 범위인지 판단한다
- [x] 4 이상일 경우, 자동차의 전진 거리를 증가시킨다
- [x] 입력된 횟수만큼 모든 자동차들이 전진 혹은 멈춘다

5. 우승자 판별

- [x] 자동차들 중 가장 멀리 이동한 거리를 찾는다
- [x] 가장 멀리 이동한 자동차들을 찾는다

출력 기능

1. 차수별 실행 결과

- [x] 입력한 이름으로 자동차를 출력한다
- [x] 전진 횟수는 `-`로 표시한다

2. 최종 우승자 안내 문구

- [x] 참여한 자동차 이름을 출력한다
- [x] 공동 우승자는 `,` 로 합산하여 표시한다

<br>

### 프로그래밍 요구사항 체크리스트

- [x] indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현한다. 2까지만 허용한다.
    - 예를 들어 while문 안에 if문이 있으면 들여쓰기는 2이다.
    - 힌트: indent(인덴트, 들여쓰기) depth를 줄이는 좋은 방법은 함수(또는 메서드)를 분리하면 된다.
- [x] 3항 연산자를 쓰지 않는다.
- [x] 함수(또는 메서드)가 한 가지 일만 하도록 최대한 작게 만들어라.
- [x] JUnit 5와 AssertJ를 이용하여 정리한 기능 목록이 정상적으로 작동하는지 테스트 코드로 확인한다.
